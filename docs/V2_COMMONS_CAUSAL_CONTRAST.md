# POLIS v2 Commons Causal Contrast

The central Commons contrast is **visible cap versus hidden cap**.

Both conditions mechanically apply the same cap of 30. They differ only in whether the agent is told the numerical maximum.

Therefore, among otherwise matched worlds and objective framings, a difference in cap-seeking behavior between these conditions is evidence about the behavioral salience of the rule representation rather than the direct mechanical consequence of the cap itself.

The visible-cap-plus-truthful-norm condition tests whether explicitly framing the number as a maximum rather than a target attenuates any cap-seeking response.
