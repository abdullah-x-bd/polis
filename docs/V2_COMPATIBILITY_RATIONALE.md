# POLIS v2 compatibility-first endpoint selection

The v2 research question concerns institutional behavior, not which commercial endpoint exposes a particular API feature. Therefore technical endpoint compatibility is treated as a precondition for measurement rather than as an experimental outcome.

The replacement endpoints were selected before confirmatory collection and preserve the intended family-diversity roles while using current OpenRouter models that expose the output-format parameter needed for the strict POLIS action schema.

This prevents a mid-run endpoint failure from creating differential missingness across governance conditions or model families.
