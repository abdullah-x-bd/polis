# POLIS v0.1 grant summary

Project AWARE will use POLIS to test whether machine-executable institutions can reduce unsafe delegation in multi-agent AI systems.

The first funded phase will replace the scripted policy with model-backed agents and run controlled comparisons across at least two model families. The study will compare no-governance, prompt-only, and coded-regulator conditions. It will report rule evasion alongside legitimate performance.

The immediate funding bottleneck is model access, experiment orchestration, engineering time, and independent technical review. The intended outputs are an open-source environment, POLIS Benchmark v0.1, raw reproducibility materials, and a technical report.
