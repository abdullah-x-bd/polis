# POLIS v2 Ethics and Responsible Use

POLIS v2 uses synthetic organizational tasks, synthetic principals, synthetic artifacts and synthetic resource-allocation worlds. No personal, confidential, customer, employee, patient, financial-client or government data are used.

The delegation study evaluates institutional policy compliance and circumvention in a controlled setting. It does not provide instructions for bypassing real access controls or exfiltrating real information. The transformations are abstract actions inside a toy environment whose purpose is to test whether policy metadata persists across representation changes.

Raw model outputs may contain unexpected text. Public release should preserve auditability while checking that no provider-generated sensitive content or credential is present. API keys are never stored in source records.

The benchmark is intended for research on multi-agent safety, evaluation, mechanism design and institutional governance. It should not be represented as a production security certification.
