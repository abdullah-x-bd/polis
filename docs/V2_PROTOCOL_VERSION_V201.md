# POLIS v2.0.1 protocol amendment

This amendment changes model endpoints only. The environments, scenario universe, governance regimes, pressure levels, metrics, hypotheses, sample sizes, statistical analysis, inference temperature, output limit, and random seed are unchanged from the previously frozen v2 design.

Reason: three frontier endpoints failed the strict technical compatibility smoke before any confirmatory v2 research episode was collected.

The replacement endpoint panel is documented in `V2_ENDPOINT_SUBSTITUTIONS_V201.md` and `V2_MODEL_PANEL_V201.md`.

Because the model identifiers are part of the canonical configuration, this amendment changes the study fingerprint and supersedes the unexecuted v2.0.0 endpoint panel for confirmatory collection.
