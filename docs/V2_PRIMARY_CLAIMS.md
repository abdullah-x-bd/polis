# POLIS v2 Primary Claim Hierarchy

These claims are ordered before paid v2 collection.

## Primary Claim 1

Governance architecture interacts with goal-policy conflict pressure. Prompt-based governance is expected to lose safety more rapidly as the policy-conflicting route becomes privately more valuable, while executable guards should preserve realized safety more consistently.

## Primary Claim 2

Recoverable executable governance should recover useful completion after blocked unsafe attempts, reducing the apparent safety-performance penalty observed under v1 terminal enforcement.

## Primary Claim 3

If provenance-informed prompting remains materially less safe than provenance-aware executable enforcement, the advantage cannot be attributed solely to the institution possessing information unavailable to the agent.

## Primary Claim 4

Visible numerical quota rules can alter agent demand behavior beyond the identical hidden mechanical cap, demonstrating that institutional representation can itself create behavioral effects.

## Robustness Claims

- governance effects should survive surface-equivalent wording changes
- executable governance should reduce between-composition safety variance in heterogeneous model societies
- a high-conflict frontier-model subset should reveal whether the main institutional patterns extend beyond the inexpensive backbone

Secondary endpoints explain mechanisms and are not used to substitute for failed primary outcomes.
