# POLIS 0.3.0 Release Notes

POLIS 0.3.0 is the first release containing the completed **v2.0.8 confirmatory institutional-governance study**.

The release adds a fresh 5,280-episode multi-study benchmark covering optimization pressure, recoverable executable enforcement, information versus enforcement, provenance laundering, wording robustness, heterogeneous model teams, quota salience, and a frontier-model diagnostic.

## Headline findings

- No institution produced a 12.0% realized violation rate in the main Delegation study. Constitutional prompting and the recoverable provenance guard both produced 0/384 realized violations.
- Provenance enforcement safely recovered 44/51 blocked main-study episodes and retained 95.6% pooled compliant completion.
- Live agents actually exploited mutable local policy representation. The local guard failed in 22/96 transformation-laundering episodes while the provenance guard failed in 0/96, exact paired p = 4.77e-7. DeepSeek V3.2 accounted for 18 of the 22 local-guard laundering violations.
- Visible numerical caps caused significantly more cap-seeking than mechanically identical hidden caps. A request-only-need norm eliminated observed cap-seeking in both Commons objective framings.
- Strong constitutional prompting was surprisingly robust, including 0/384 main-study violations and 0% frontier-subset violations. The result argues against the simplistic claim that executable governance always beats prompting.
- An exploratory GPT-4.1 Mini result shows a striking collective-action pathology: a total-welfare objective caused some agents to request system-scale quantities independently, reducing allocation efficiency despite apparently prosocial reasoning.
