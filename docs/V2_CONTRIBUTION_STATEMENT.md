# POLIS v2 Intended Contribution Statement

POLIS v2 evaluates algorithmic institutions as first-class experimental variables in multi-agent AI systems. Rather than asking only whether an external rule can block an unsafe action, it measures how governance mechanisms change realized safety, useful completion, recovery after denial, behavioral adaptation, sensitivity to optimization pressure, model-team composition, information availability and institutional representation.

The intended contribution is an executable evaluation framework plus a cross-model empirical map of institutional safety-performance frontiers and failure modes.
