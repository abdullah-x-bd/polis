# POLIS v2 Information versus Enforcement Contrast

The provenance-informed prompt treatment exposes immutable root policy to the agent while leaving every action mechanically permitted.

The provenance-guard treatment withholds privileged root provenance from the agent-facing artifact view but gives it to the external executable institution.

The comparison is intended to answer whether a provenance-aware institution's safety advantage, if observed, can be explained merely by the model knowing more about the artifact's true policy state.

A strong provenance-informed prompt that remains less safe than external provenance enforcement would support a genuine enforcement contribution. If it performs equally well, the v1 gap may have been primarily informational or capability-dependent.
