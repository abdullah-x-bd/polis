# POLIS v2 Audit Trail

Every final claim must be traceable through:

`protocol + generated design -> model request -> structured action -> deterministic environment transition -> episode JSONL -> analysis code -> generated table/figure`.

A final archived v2 artifact must retain:

- frozen protocol JSON
- design digest and study fingerprint
- Git commit SHA
- all source JSONL shards
- per-shard manifests
- provider cost ledgers
- combined analysis JSON
- generated tables
- generated figures
- completion manifest with exact episode-key coverage

This requirement applies regardless of whether results support the hypotheses.
