# POLIS v2 Source-Data Policy

The source scientific data are the episode-level JSONL records produced by the frozen live runner.

Generated CSVs, tables, figures and Markdown summaries are derived artifacts. If a derived artifact conflicts with source JSONL, the source record plus frozen analysis code is authoritative.

No source episode may be edited by hand. Infrastructure reruns resume missing keys; they do not overwrite completed keys solely to obtain a different model outcome.
