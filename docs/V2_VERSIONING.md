# POLIS v2 Versioning

`2.0.0` denotes the first frozen v2 confirmatory protocol.

If a substantive scientific variable changes after freeze, the new protocol receives a new version and fingerprint. Operational fixes that alter prompts, state transitions, action validity, model routing, sample assignment or outcome computation are substantive for this purpose.

The package release version and scientific protocol version are related metadata but the protocol fingerprint is the authoritative identifier for one confirmatory dataset.
