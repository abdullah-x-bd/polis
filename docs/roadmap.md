# Roadmap

## v0.1: runnable institutional baseline

- Scripted unsafe-delegation environment
- Three governance regimes
- External coded regulator
- Reproducible audit logs
- Operational safety and performance metrics

## v0.2: model-backed agents

- Provider-neutral agent interface
- At least two model families
- Fixed task suite and repeated seeds
- Prompt-injection and leakage checks

## v0.3: adaptive evasion

- Indirect delegation
- Task decomposition
- False labels
- Regulator avoidance
- Strategic behaviour after intervention

## v0.4: plural authority

- Conflicting principals
- Several regulators
- Appeals and review
- Jurisdiction rules

## Benchmark v1

- Public task specification
- Cross-model comparison
- Baseline institutional regimes
- Independent technical review
- Research report and reproducibility package
