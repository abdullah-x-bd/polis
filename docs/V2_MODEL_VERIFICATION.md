# POLIS v2 Model Endpoint Verification

Before the confirmatory dataset is collected, every frozen model slug receives one technical structured-output smoke request. These requests are not experimental episodes and are not included in the v2 analysis.

OpenRouter model catalog verification immediately before the smoke test confirmed the frozen identifiers/pricing targets for DeepSeek V4 Flash, Qwen3.7 Max, Claude Sonnet 5, and GPT-5.5. The existing v1 run already exercised Gemini 2.5 Flash-Lite, Mistral Small, and GPT-4.1 Mini, but all seven endpoints are smoked under the same current adapter for completeness.

If a model endpoint cannot execute the strict structured action schema, the model panel must be repaired before confirmatory data collection and the scientific protocol re-frozen under a new fingerprint. A model cannot be silently dropped after v2 outcomes are observed.
